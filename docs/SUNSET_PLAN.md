# Imgponic サンセットプラン

## 概要

Imgponic プロジェクトは `v1.0.0` を最終リリースとして撤退手続き中です。本ドキュメントでは、利用継続に際して必要となる最小限の確認事項と問い合わせ窓口をまとめます。

## 主なマイルストン

- 2025-02-28: メンテナンス終了（セキュリティ修正を含むすべての更新を停止）
- 2025-03-15: 最終リリース `v1.0.0` をアーカイブ確定
- 2025-04-30: サポート窓口の一次対応終了

## 利用者向けチェックリスト

1. **最終リリースの取得**: GitHub Releases で公開している `v1.0.0` をダウンロードし、ハッシュ値を保存してください。以降は再発行しません。
2. **ログ保全**: `runs/<timestamp>/` 以下の生成履歴は業務証跡として各組織でバックアップしてください。特にコンプライアンス用途では書き戻しを禁止します。
3. **問い合わせ窓口**: 運用やライセンスに関する質問は `sunset@imgponic.dev`（対応時間: 平日 10:00-16:00 JST）へメールでご連絡ください。

## ライセンスと再配布

MIT ライセンスは継続しますが、Imgponic 名義での新規リリースは行いません。フォークや内部利用時は、改変箇所とサポート責任範囲を各組織で明確化してください。

## FAQ

- **Q. セキュリティパッチは提供されますか？**
  - A. いいえ。既知・未知の脆弱性に対する修正は提供しません。必要に応じてフォークで対処してください。
- **Q. ログ出力の位置は変わりますか？**
  - A. 撤退後も `runs/<timestamp>/` 配下に出力されます。アプリの設定 UI から保存先を変更しないようにしてください。
- **Q. 問い合わせメールの応答が無かった場合は？**
  - A. 3 営業日以内に返答が無い場合、撤退済みとして個別対応が終了した可能性があります。緊急時はプロジェクトの GitHub Issue に参考情報を残してください（解決を保証しません）。
